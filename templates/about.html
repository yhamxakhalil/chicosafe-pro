About Chico Safe

Chico Safe is a free, web-based intelligent password security system built as a final-year software engineering project. It combines three essential tools into one secure, user-authenticated platform: a real-time password strength analyzer, a cryptographically secure password generator, and an encrypted personal password vault.

Why Chico Safe?

Most people reuse weak passwords because remembering many strong, unique ones is difficult. Chico Safe solves this by helping users analyze their current passwords, generate stronger replacements, and store everything securely in one place, protected by encryption that only they can unlock.

Security

Every password you store is encrypted with AES-128 (Fernet) using a key that is unique to your account. Your master password is never stored only a one-way salted hash is kept. Email verification via a One-Time Password (OTP) ensures only you can activate your account.
